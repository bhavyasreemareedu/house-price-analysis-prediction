# House Price Analysis and Prediction

## Project Overview
This project focuses on analysing housing data and predicting house prices using Python and Machine Learning. It explores how different housing features influence property prices and builds predictive models to estimate house prices.

## Objectives
- Understand and analyse housing data.
- Identify and handle missing values and duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Visualize relationships between house features and prices.
- Build and evaluate Machine Learning regression models.
- Predict house prices using new sample inputs.

## Dataset
The project uses `Housing.csv`, containing 545 house records and 13 columns.

**Features include:**
- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status
- Price (Target Variable)

## Model Evaluation
The models are evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
